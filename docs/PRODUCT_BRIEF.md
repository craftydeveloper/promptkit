# Product brief — PromptKit

## Purpose

A local library for reusable prompt templates and task briefs.

## Main workflow

Save a template, mark variables, search by task, fill approved information, and review the resulting output.

## Scope

The current page is a prototype. Roadmap items and sample records in this repository are documentation, not claims that those features already exist. A successful session lets a user complete the core task and understand whether the information is local or externally sourced.
